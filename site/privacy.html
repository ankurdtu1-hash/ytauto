Privacy Policy – ytauto

Last updated: 28 October 2026

1. What ytauto is

ytauto is a personal script used only by its owner to upload videos to the owner's own YouTube channel. It has no other users and no public interface.

2. YouTube API Services

ytauto uses YouTube API Services. By using ytauto you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Data accessed and how it is used

With the owner's permission (Google OAuth), ytauto uses the YouTube Data API to:

  • upload videos to the owner's channel (videos.insert),
  • set thumbnails for those videos (thumbnails.set),
  • read basic information about the owner's own channel (channels.list).

ytauto does not access, collect or store data about any other YouTube user, viewer or channel.

4. Storage and sharing

The only stored data is the owner's OAuth access/refresh token, kept on the owner's private server and computer. No data is sold, shared with third parties or used for advertising. No cookies or tracking are used on this website.

5. Data retention and deletion

The OAuth token is kept only while ytauto is in use. To delete it:

  • revoke access at https://myaccount.google.com/permissions (Google security settings) – the stored token stops working immediately; and
  • the owner deletes the token.json file from the server.

Any stored API data is deleted or refreshed within 30 days, in line with the YouTube API Services Developer Policies.

6. Google policies

ytauto follows the YouTube API Services Developer Policies and the Google API Services User Data Policy.

7. Contact

Questions about this policy can be sent through the contact details on the owner's YouTube channel.
